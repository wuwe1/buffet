# 致股东的信（Shareholder Letters）

巴菲特自 1977 年起每年为伯克希尔·哈撒韦股东撰写年度信件，至 2024 年共 48 封。这些信是学习巴菲特投资哲学最直接、最权威的一手材料——没有中间人转述，没有媒体剪裁，是他本人对股东的坦诚对话。

本目录收录了全部 48 封信的 Markdown 版本（`1977.md` ~ `2024.md`）。

---

## 从哪里开始？

48 封信全读一遍当然最好，但如果时间有限，以下是分阶段的阅读建议。

### 第一阶段：必读 5 封（建立核心框架）

如果只能读 5 封，读这些。它们覆盖了巴菲特最重要的投资原则：

| 年份 | 为什么必读 |
|------|-----------|
| [1983](1983.md) | **巴菲特宪章**。信中列出了 13 条"股东相关的商业原则"（Owner-Related Business Principles），是理解伯克希尔一切决策的基石。同时详述了收购内布拉斯加家具城（NFM）的故事——完美展示了他心目中的理想生意。 |
| [1989](1989.md) | 提出"穿透盈利"（Look-Through Earnings）概念，解释为什么会计利润不等于经济利润。用"Rip Van Winkle"比喻阐述长期持有的税收优势。 |
| [1992](1992.md) | 系统阐述"以合理价格买好公司，而非以好价格买平庸公司"的核心理念。详述了 GEICO 和可口可乐的投资逻辑。 |
| [2007](2007.md) | 对"护城河"（Economic Moat）最完整的论述：什么是真正的持久竞争优势，什么是虚假护城河。还有对"好生意 vs 烂生意"的精辟分类。 |
| [2024](2024.md) | 巴菲特 94 岁时的最新信。坦诚谈论错误，讲述 Pete Liegl 和 Forest River 的精彩故事，展示了他如何评估管理者。 |

### 第二阶段：进阶 7 封（深入理解投资方法论）

读完第一阶段后，这些信会让你理解得更深：

| 年份 | 核心内容 |
|------|---------|
| [1977](1977.md) | **起点**。巴菲特第一封致股东信，阐明用股本回报率（ROE）而非每股收益（EPS）衡量管理层表现。提出"顺风行业 vs 逆风行业"的重要洞见。 |
| [1979](1979.md) | 深入讨论通胀对投资者的致命威胁（"投资者痛苦指数"），区分"经济利润"与"会计利润"——对理解巴菲特的估值方法至关重要。 |
| [1985](1985.md) | 关闭纺织业务的深刻反思：再好的管理层也无法战胜糟糕的行业经济特征。同年完成了对 Capital Cities/ABC 的重大投资。 |
| [1994](1994.md) | 用 Scott Fetzer 案例详解"账面价值 vs 内在价值"的差异——内在价值大幅增长，而账面价值却在下降。对资本配置和管理层激励的深度讨论。 |
| [1996](1996.md) | 完整收购 GEICO 后，对保险浮存金（Float）原理的最佳解释——理解伯克希尔商业模式的关键。 |
| [2001](2001.md) | 9/11 之后写就。提出保险承保三原则，展示巴菲特如何在危机中思考风险。 |
| [2008](2008.md) | 金融危机中的冷静思考。在市场恐慌中进行战略投资（高盛、通用电气），同时坦承自己的投资失误。践行了"别人恐惧时贪婪"。 |
