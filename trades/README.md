# 交易复盘

对巴菲特重大投资案例的系统复盘。

## 复盘框架

每笔交易按以下维度分析：

1. **标的概况**：公司基本面与行业背景
2. **买入逻辑**：为什么买？估值如何？
3. **持有过程**：持有期间的关键事件与心态
4. **卖出/持有至今**：退出时机与原因，或长期持有的理由
5. **收益与教训**：最终回报与可复制的经验

## 经典案例

- 美国运通（American Express）
- GEICO
- 华盛顿邮报（Washington Post）
