# 核心投资理念

系统梳理巴菲特的投资哲学与决策框架。

## 核心原则

### 能力圈（Circle of Competence）
只投资自己真正理解的企业。

### 护城河（Economic Moat）
寻找具有持久竞争优势的企业——品牌、网络效应、成本优势、转换成本等。

### 安全边际（Margin of Safety）
以低于内在价值的价格买入，为判断失误留出缓冲。

### 内在价值（Intrinsic Value）
企业在其剩余存续期内可以产出的现金流的折现值。

### 市场先生（Mr. Market）
市场是你的仆人，而非你的主人。利用市场的非理性，而非被其左右。

### 长期持有
"我最喜欢的持有期限是永远。" 复利是投资者最强大的武器。

### 管理层质量
投资于诚实、能干、以股东利益为导向的管理团队。

### 逆向思维
"在别人贪婪时恐惧，在别人恐惧时贪婪。"
