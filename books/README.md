# 相关书籍笔记

关于巴菲特的经典书籍与推荐阅读。

## 核心书单

- **《巴菲特致股东的信》**（The Essays of Warren Buffett）— Lawrence Cunningham 编
- **《滚雪球》**（The Snowball）— Alice Schroeder
- **《巴菲特之道》**（The Warren Buffett Way）— Robert Hagstrom
- **《聪明的投资者》**（The Intelligent Investor）— Benjamin Graham
- **《证券分析》**（Security Analysis）— Benjamin Graham & David Dodd
- **《穷查理宝典》**（Poor Charlie's Almanack）— Peter Kaufman 编

## 笔记格式

每本书的笔记包含：
- 核心论点摘要
- 关键章节笔记
- 与巴菲特投资实践的关联
- 个人思考与启发
