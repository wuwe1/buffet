# Buffett Research

梳理沃伦·巴菲特（Warren Buffett）的投资理论、演讲、文章、书籍，复盘他的交易与投资理念。

## 目录结构

```
.
├── letters/            # 致股东的信（Shareholder Letters）
├── talks/              # 演讲与访谈
├── trades/             # 交易复盘
├── principles/         # 核心投资理念
├── books/              # 相关书籍笔记
└── articles/           # 文章与媒体报道
```

## letters/ — 致股东的信

巴菲特每年发布的伯克希尔·哈撒韦致股东信，是理解其投资哲学最重要的一手材料。

## talks/ — 演讲与访谈

包括大学演讲、股东大会问答、电视访谈等。

## trades/ — 交易复盘

对巴菲特重大投资交易的分析与复盘，包括买入逻辑、持有过程、卖出时机等。

## principles/ — 核心投资理念

系统梳理巴菲特的投资原则，如：
- 能力圈（Circle of Competence）
- 护城河（Economic Moat）
- 安全边际（Margin of Safety）
- 内在价值（Intrinsic Value）
- 市场先生（Mr. Market）

## books/ — 相关书籍笔记

关于巴菲特的经典书籍阅读笔记。

## articles/ — 文章与媒体报道

巴菲特本人撰写或关于他的重要文章。
